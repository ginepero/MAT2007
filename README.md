# Project README
**Overview:**
The project investigates how electricity produced from nuclear energy has changed in Belgium, France, Germany, Italy and the Netherlands between 1965 and 2025. 
Thus, the research question for this project is: "How has nuclear energy (electricity) production in Belgium, France, Germany, Italy and the Netherlands changed from 1965 to 2025?"

**Code:**
The code was made in python via visual studio code.

To run the code 2 libraries are needed:
  (1) pandas #needed to read CSV files, works with data tables, etc.
  (2) matplotlib.pyplot #needed to create the plots
  
The dataset is from Our World in Data and includes global data from 1900 to 2025, the full dataset can be accessed here: 
  https://ourworldindata.org/grapher/electricity-mix?tab=table&source=nuclear&metric=generation&frequency=annual

**Step 1:** Make sure you are working with Python3 in visual studio code (or any other platform that supports Python3)

**Step 2:** Create a folder and new file

**Step 3:** Make sure the 2 aforementioned libraries are installed (e.g. pip3 install pandas)

**Step 4:** Import the CSV file (the full original dataset) into your workspace, the code already includes a section designed to clean up the data and include only data from Belgium, France, Germany, Italy and the Netherlands between 1965 and 2025. This will create a new CSV file with only the relevant data.

**Step 5:** Run the python file and 2 graphs will be generated

**Note:** In case you want to look at other countries and generate different graphs you can replace one of the 5 countries (or more) with other countries.
